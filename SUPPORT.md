## Getting Help

- [GitHub Issues](https://github.com/caberdo/terraform-provider-gravitino/issues) — bug reports,
  feature requests and questions. Bug reports and feature requests have templates; GitHub
  Discussions is disabled on this repository, so questions are answered in issues.
- [Contributing](.github/CONTRIBUTING.md) — development setup, tests and the pull request process.

## Reporting Security Issues

Report suspected vulnerabilities privately, never in a public issue. See
[`.github/SECURITY.md`](.github/SECURITY.md) for the process, the response timelines and what to
include.
