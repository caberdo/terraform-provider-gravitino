# gravitino_metalake Resource



## Example Usage

```terraform
resource "gravitino_metalake" "minimal" {
  name = "minimal_metalake"
}

resource "gravitino_metalake" "example" {
  name    = "example_metalake"
  comment = "Example metalake for development"
  properties = {
    env = "dev"
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import an existing metalake by its name.
terraform import gravitino_metalake.example my_metalake
```
