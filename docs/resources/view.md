# gravitino_view Resource

Manages a Gravitino view within a metalake, catalog, and schema.

## Example Usage

```terraform
resource "gravitino_view" "user_summary" {
  metalake = gravitino_metalake.example.name
  catalog  = gravitino_catalog.hive.name
  schema   = gravitino_schema.example.name
  name     = "user_summary"
  comment  = "View aggregating user data"

  column = [{
    name    = "id"
    type    = "long"
    comment = "user id"
  }]

  representation = [{
    type    = "sql"
    dialect = "trino"
    sql     = "SELECT u.id, COUNT(o.order_id) AS order_count FROM users u LEFT JOIN orders o ON u.id = o.customer_id GROUP BY u.id"
  }]
}

resource "gravitino_view" "active_customers" {
  metalake = gravitino_metalake.example.name
  catalog  = gravitino_catalog.hive.name
  schema   = gravitino_schema.example.name
  name     = "active_customers"
  comment  = "Customers with orders in last 90 days"

  column = [{
    name     = "id"
    type     = "long"
    comment  = "customer id"
    nullable = false
  }]

  representation = [{
    type    = "sql"
    dialect = "trino"
    sql     = "SELECT DISTINCT u.id, u.email FROM users u INNER JOIN orders o ON u.id = o.customer_id WHERE o.order_date >= current_date - INTERVAL '90' DAY"
  }]

  default_catalog = gravitino_catalog.hive.name
  default_schema  = gravitino_schema.example.name

  properties = {
    "refresh" = "daily"
    "owner"   = "analytics-team"
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import an existing view by metalake, catalog, schema and view name.
terraform import gravitino_view.example my_metalake.my_catalog.my_schema.my_view
```

## Schema

### Required

- `catalog` (String) The catalog name.
- `metalake` (String) The metalake name.
- `name` (String) The view name. Gravitino renames views in place through the `rename` update.
- `representation` (Attributes List) The representations of the view body, keyed by dialect. At least one is required. Changing them forces a new view. (see [below for nested schema](#nestedatt--representation))
- `schema` (String) The schema name.

### Optional

- `column` (Attributes List) The output columns of the view. When omitted Gravitino derives them from the representations. Changing the columns forces a new view. (see [below for nested schema](#nestedatt--column))
- `comment` (String) A comment describing the view. Gravitino v1.3.0 has no view comment update operation, so changing the comment replaces the view.
- `default_catalog` (String) The default catalog used to resolve unqualified identifiers in the view representations. Changing it replaces the view.
- `default_schema` (String) The default schema used to resolve unqualified identifiers in the view representations. Changing it replaces the view.
- `properties` (Map of String) Key-value properties for the view.

### Read-Only

- `audit` (Object) Audit information for the view. (see [below for nested schema](#nestedatt--audit))
- `id` (String) Compound identifier in the format metalake.catalog.schema.view.
