# gravitino_statistics Resource

Manages the modifiable (custom) statistics of one Gravitino metadata object. The resource owns the whole modifiable set: a statistic that exists on the server but not in this map is dropped on the next apply, and a statistic that disappeared on the server is written again. Reserved, catalog-supplied statistics (for example Iceberg's row count) are ignored by Read and never dropped. Gravitino 1.3.x implements statistics for TABLE objects only.

## Example Usage

```terraform
# Gravitino stores statistics per metadata object. Reserved statistics such as
# row_count are supplied by the catalog and cannot be written through Gravitino;
# this resource owns the custom-* statistics, and a write outside Terraform is
# either re-applied or dropped on the next apply.
resource "gravitino_statistics" "orders" {
  metalake         = gravitino_metalake.example.name
  object_type      = "TABLE"
  object_full_name = "sales.orders"

  statistics = {
    "custom-row-count"  = "1000"
    "custom-total-size" = "20480"
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import the statistics of a metadata object by metalake, object type and object
# full name (relative to the metalake).
terraform import gravitino_statistics.example my_metalake.TABLE.sales.orders
```

## Schema

### Required

- `metalake` (String) The metalake the object belongs to. Changing this forces replacement.
- `object_full_name` (String) The full name of the metadata object relative to the metalake, for example 'my_catalog' for a CATALOG, 'my_catalog.my_schema' for a SCHEMA and 'my_catalog.my_schema.my_table' for a TABLE. Do not prefix it with the metalake name. Changing this forces replacement.
- `object_type` (String) The metadata object type, one of: METALAKE, CATALOG, SCHEMA, TABLE, VIEW, COLUMN, FILESET, TOPIC, MODEL, FUNCTION, ROLE. Gravitino 1.3.x only implements statistics for TABLE and rejects every other type with 400. VIEW and FUNCTION require Gravitino >= 1.3.1 and are rejected on an older server with an explicit diagnostic. Changing this forces replacement.
- `statistics` (Map of String) Custom statistics as a map of statistic name to value. Names must start with 'custom-' and be at most 128 characters, which is the only shape Gravitino 1.3.x accepts on write. Gravitino's update request is untyped JSON (`additionalProperties: {}`), but the provider writes every value as a JSON string and renders the value read back as a string: a numeric, boolean or structured value written by another client appears as its JSON encoding and is rewritten as a string on the next apply. Set it to {} to drop every statistic this resource manages while keeping the resource.

### Read-Only

- `id` (String) Composite identifier in the format 'metalake.object_type.object_full_name'.
