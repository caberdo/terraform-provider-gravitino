# gravitino_policy Resource



## Example Usage

```terraform
# A custom policy is applied to metadata objects (catalogs, schemas, tables,
# filesets, topics, models) and managed through the custom policy content.
resource "gravitino_policy" "data_retention" {
  metalake = gravitino_metalake.example.name
  name     = "data_retention"
  comment  = "Retain data for compliance"

  policy_type = "custom"
  enabled     = true

  # One or more of CATALOG, SCHEMA, TABLE, FILESET, TOPIC, MODEL.
  supported_object_types = ["CATALOG", "SCHEMA", "TABLE"]

  properties = {
    key1 = "value1"
  }

  # The API accepts any JSON value per rule; because this map is string-typed in
  # Terraform, non-string server values are rendered as their JSON encoding
  # (the server value 123 is read back as "123").
  custom_rules = {
    rule1 = "123"
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import an existing policy by metalake and policy name.
terraform import gravitino_policy.example my_metalake.my_policy
```

## Schema

### Required

- `metalake` (String) The metalake name.
- `name` (String) The policy name. Renaming is performed in-place via the API's rename update.
- `supported_object_types` (Set of String) The object types this policy supports. One or more of: CATALOG, SCHEMA, TABLE, FILESET, TOPIC, MODEL. Updated in-place through the API's updateContent request.

### Optional

- `comment` (String) A comment or description for the policy.
- `custom_rules` (Map of String) A map of custom rules for the policy. The API accepts any JSON value per rule; non-string server values are rendered as their JSON encoding (e.g. the number 123 as "123").
- `enabled` (Boolean) Whether the policy is enabled. Toggled through the API's setPolicy (PATCH) endpoint.
- `policy_type` (String) The policy type. Only 'custom' is currently supported. Changing it requires creating a new policy.
- `properties` (Map of String) A map of key-value properties for the policy.

### Read-Only

- `audit` (Object) Audit information for the policy. (see [below for nested schema](#nestedatt--audit))
- `id` (String) Composite identifier in the format 'metalake.policy_name'.
