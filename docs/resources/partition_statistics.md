# gravitino_partition_statistics Resource

Manages the modifiable (custom) statistics of the partitions of one Gravitino table. The resource owns the whole modifiable set: a partition statistic that exists on the server but not in this map is dropped on the next apply, and a partition that is removed from the map loses every statistic this resource manages. Gravitino 1.3.x implements partition statistics for TABLE objects only.

## Example Usage

```terraform
# Partition statistics are keyed by partition name, then by statistic name.
# Like gravitino_statistics, the resource owns every custom-* entry it manages.
resource "gravitino_partition_statistics" "orders" {
  metalake = gravitino_metalake.example.name
  catalog  = gravitino_catalog.hive.name
  schema   = gravitino_schema.example.name
  table    = gravitino_table.partitioned.name

  partitions = {
    "dt=2026-10-01" = {
      "custom-row-count" = "500"
    }
    "dt=2026-10-02" = {
      "custom-row-count" = "750"
      "custom-size"      = "1024"
    }
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import the partition statistics of a table by metalake, catalog, schema and table.
terraform import gravitino_partition_statistics.example my_metalake.my_catalog.my_schema.my_table
```

## Schema

### Required

- `catalog` (String) The catalog the table belongs to. Changing this forces replacement.
- `metalake` (String) The metalake the table belongs to. Changing this forces replacement.
- `partitions` (Map of Map of String) Partition statistics as a map of partition name to a map of statistic name and value. Statistic names must start with 'custom-' and be at most 128 characters, which is the only shape Gravitino 1.3.x accepts on write. Values cross the provider boundary as strings, like gravitino_statistics. Set it to {} to drop every partition statistic this resource manages while keeping the resource.
- `schema` (String) The schema the table belongs to. Changing this forces replacement.
- `table` (String) The table whose partition statistics are managed. Changing this forces replacement.

### Read-Only

- `id` (String) Composite identifier in the format 'metalake.catalog.schema.table'.
