# gravitino_catalog Resource



## Example Usage

```terraform
resource "gravitino_catalog" "hive" {
  metalake         = gravitino_metalake.example.name
  name             = "hive_catalog"
  type             = "relational"
  catalog_provider = "hive"
  comment          = "Hive catalog for data warehouse"
  properties = {
    "metastore.uris" = "thrift://localhost:9083"
  }
}

resource "gravitino_catalog" "fileset" {
  metalake = gravitino_metalake.example.name
  name     = "fileset_catalog"
  type     = "fileset"
  comment  = "Fileset catalog for data lake"
}

resource "gravitino_catalog" "lakehouse_iceberg" {
  metalake         = gravitino_metalake.example.name
  name             = "lakehouse_iceberg_catalog"
  type             = "relational"
  catalog_provider = "lakehouse-iceberg"
  comment          = "Lakehouse Iceberg catalog for transactional data lake"
  properties = {
    "warehouse"       = "s3a://iceberg-warehouse"
    "catalog-backend" = "jdbc"
    "uri"             = "jdbc:postgresql://localhost:5432/iceberg"
  }
}
```

## Import

Import is supported using the following syntax:

```shell
# Import an existing catalog by the metalake and catalog name.
terraform import gravitino_catalog.example my_metalake.my_catalog
```

## Schema

### Required

- `metalake` (String) The metalake name.
- `name` (String) The catalog name.
- `type` (String) The catalog type. Must be one of: relational, fileset, messaging, model. Changing the type forces a new catalog: the Gravitino API has no update request for it.

### Optional

- `catalog_provider` (String) The catalog provider. Must be one of: hive, lakehouse-iceberg, lakehouse-paimon, lakehouse-hudi, jdbc-mysql, jdbc-postgresql, jdbc-doris, jdbc-oceanbase, kafka, fileset, model. Changing the provider forces a new catalog: the Gravitino API has no update request for it.
- `comment` (String) A comment or description for the catalog. The Gravitino API can only replace an existing comment (updateComment), never remove it.
- `properties` (Map of String, Sensitive) A map of key-value properties for the catalog. May contain credentials (for example JDBC passwords or S3 keys), therefore it is marked sensitive. The reserved 'in-use' key is managed by Gravitino (PATCH .../catalogs/{name}) and cannot be configured here.

### Read-Only

- `audit` (Object) Audit information for the catalog. (see [below for nested schema](#nestedatt--audit))
- `id` (String) Composite identifier in the format 'metalake.catalog_name'.
