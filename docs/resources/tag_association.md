# gravitino_tag_association Resource

Attaches tags to a catalog, schema, table, view, column, fileset, topic, model or function in a metalake. Only direct associations are managed: tags inherited from a parent object are ignored by Read and are never removed by destroy. Gravitino exposes no DELETE for an association, so destroy sends one associateTags request with tagsToRemove for every tag in state.

## Example Usage

```terraform
# Attach existing tags directly to a metadata object. The object is identified
# by its type and its full name relative to the metalake (without the metalake
# prefix). Adding or removing entries updates the association in place; destroy
# detaches every tag this resource manages.
resource "gravitino_tag_association" "orders_pii" {
  metalake         = gravitino_metalake.example.name
  object_type      = "TABLE"
  object_full_name = "sales.orders"
  tags             = [gravitino_tag.pii.name, gravitino_tag.confidential.name]
}

# A column carries tags with its own full name, including the table name.
resource "gravitino_tag_association" "orders_email_column" {
  metalake         = gravitino_metalake.example.name
  object_type      = "COLUMN"
  object_full_name = "sales.orders.email"
  tags             = [gravitino_tag.pii.name]
}
```

## Import

Import is supported using the following syntax:

```shell
# Import an existing tag association by metalake, object type and object full name.
terraform import gravitino_tag_association.example my_metalake.TABLE.sales.orders
```

## Schema

### Required

- `metalake` (String) The metalake name. Changing this forces the association to be recreated.
- `object_full_name` (String) The full name of the metadata object relative to the metalake, for example 'my_catalog' for a CATALOG, 'my_catalog.my_schema' for a SCHEMA, 'my_catalog.my_schema.my_table' for a TABLE and 'my_catalog.my_schema.my_table.my_column' for a COLUMN. Do not prefix it with the metalake name. Changing this forces the association to be recreated.
- `object_type` (String) The metadata object type. One of: CATALOG, SCHEMA, TABLE, VIEW, COLUMN, FILESET, TOPIC, MODEL, FUNCTION. VIEW requires Gravitino >= 1.3.1 and is rejected on an older server with an explicit diagnostic.
- `tags` (Set of String) The names of the tags to attach directly to the object. Adding and removing entries is applied in place through associateTags. Set it to [] to detach every tag this resource manages while keeping the resource. Tags inherited from a parent object are not part of this set.

### Read-Only

- `id` (String) Composite identifier in the format 'metalake.object_type.object_full_name'.
