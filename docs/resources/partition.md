# gravitino_partition Resource

Manages a partition of a Gravitino table. Gravitino v1.3.0 has no API to modify an existing partition, so every change to this resource replaces the partition.

## Example Usage

```terraform
resource "gravitino_partition" "q1_2024" {
  metalake = gravitino_metalake.example.name
  catalog  = gravitino_catalog.hive.name
  schema   = gravitino_schema.example.name
  table    = gravitino_table.partitioned.name

  # Gravitino discriminates partitions by type: identity, range or list.
  type        = "identity"
  field_names = [["order_date"]]
  values = [
    {
      data_type = "date"
      value     = "2024-01-01"
    }
  ]
}

resource "gravitino_partition" "q2_2024" {
  metalake = gravitino_metalake.example.name
  catalog  = gravitino_catalog.hive.name
  schema   = gravitino_schema.example.name
```

## Import

Import is supported using the following syntax:

```shell
# Import an existing partition by metalake, catalog, schema, table and partition name.
terraform import gravitino_partition.example my_metalake.my_catalog.my_schema.my_table.partition_2024_01
```

## Schema

### Required

- `catalog` (String) The catalog the partition belongs to.
- `metalake` (String) The metalake the partition belongs to.
- `schema` (String) The schema the partition belongs to.
- `table` (String) The table the partition belongs to.
- `type` (String) The partition type: identity, range or list.

### Optional

- `field_names` (List of List of String) The identity partition fields, one entry per field, each entry holding the path segments of the field. The values must be listed in the same order.
- `lists` (List of List of Object) The value lists of a list partition, one entry per list, each entry holding the literals of that list.
- `lower` (Object) The inclusive lower bound of a range partition. (see [below for nested schema](#nestedatt--lower))
- `name` (String) The partition name. Required for range and list partitions. The catalog derives the name of an identity partition from the field names and values, so any value configured for an identity partition is ignored and the name reported by Gravitino is stored instead.
- `properties` (Map of String) Key-value properties of the partition. The catalog implementation may add its own properties (Hive adds table statistics); those are only reported when no properties are managed by this resource.
- `upper` (Object) The exclusive upper bound of a range partition. (see [below for nested schema](#nestedatt--upper))
- `values` (List of Object) The identity partition values, one literal per entry of field_names. (see [below for nested schema](#nestedatt--values))

### Read-Only

- `id` (String) The compound identifier in the format metalake.catalog.schema.table.partition.
