# gravitino_object_tags Data Source

Lists the tags attached to one metadata object. The result includes tags inherited from the object's ancestors.

## Example Usage

```terraform
# List the tags attached to a metadata object. The result includes tags
# inherited from the object's ancestors.
data "gravitino_object_tags" "orders" {
  metalake         = "example_metalake"
  object_type      = "TABLE"
  object_full_name = "sales.orders"
}
```

## Schema

### Required

- `metalake` (String) The metalake name.
- `object_full_name` (String) The full name of the metadata object relative to the metalake, for example 'my_catalog' for a CATALOG or 'my_catalog.my_schema.my_table' for a TABLE. Do not prefix it with the metalake name.
- `object_type` (String) The metadata object type. One of: CATALOG, SCHEMA, TABLE, VIEW, COLUMN, FILESET, TOPIC, MODEL, FUNCTION. VIEW requires Gravitino >= 1.3.1 and is rejected on an older server with an explicit diagnostic.

### Read-Only

- `tags` (List of String) The names of the tags attached to the object, including inherited tags.
