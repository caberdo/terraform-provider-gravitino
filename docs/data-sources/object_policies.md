# gravitino_object_policies Data Source

Lists the policies attached to one metadata object. The result includes policies inherited from the object's ancestors.

## Example Usage

```terraform
# List the policies attached to a metadata object. The result includes policies
# inherited from the object's ancestors.
data "gravitino_object_policies" "orders" {
  metalake         = "example_metalake"
  object_type      = "TABLE"
  object_full_name = "sales.orders"
}
```

## Schema

### Required

- `metalake` (String) The metalake name.
- `object_full_name` (String) The full name of the metadata object relative to the metalake, for example 'my_catalog' for a CATALOG or 'my_catalog.my_schema.my_table' for a TABLE. Do not prefix it with the metalake name.
- `object_type` (String) The metadata object type. One of: CATALOG, SCHEMA, TABLE, FILESET, TOPIC, MODEL, VIEW, FUNCTION. VIEW and FUNCTION require Gravitino >= 1.3.1 and are rejected on an older server with an explicit diagnostic. Columns cannot carry a policy.

### Read-Only

- `policies` (List of String) The names of the policies attached to the object, including inherited policies.
