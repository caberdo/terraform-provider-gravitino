# gravitino_policy_objects Data Source

Lists the metadata objects a policy is directly attached to. Objects that only inherit the policy are not included.

## Example Usage

```terraform
# List the metadata objects a policy is directly attached to.
data "gravitino_policy_objects" "data_retention" {
  metalake = "example_metalake"
  policy   = "data_retention"
}
```
